GEPEKRIS Tretes

Panduan Penyimpanan Direktori di Hosting gepekristretes.org

Dokumen ini menjelaskan struktur direktori penyimpanan konten website pada hosting gepekristretes.org.

Direktori Penyimpanan Aktif: Konten website disimpan dalam format JSON di public_html/data/church_content.json dengan cadangan otomatis di public_html/data/backups/.

1. Struktur Direktori di cPanel / Server

public_html/
├── index.html              (Halaman utama website)
├── assets/                 (Berkas CSS & JS terkompilasi)
├── api/
│   ├── content.php         (Script API penyimpan & pembaca data)
│   └── .htaccess           (Konfigurasi CORS & headers)
└── data/                   [Dibuat otomatis oleh script]
    ├── church_content.json (Berkas utama seluruh isi website)
    └── backups/            (Cadangan otomatis sebelum setiap perubahan)

2. Langkah Pengunggahan ke cPanel gepekristretes.org

  1. Login ke cPanel hosting Anda di https://gepekristretes.org:2083.
  2. Buka File Manager dan masuk ke folder public_html.
  3. Buat folder bernama api jika belum ada, lalu unggah file content.php dan .htaccess ke dalam public_html/api/.
  4. Pastikan izin folder (CHMOD) public_html/data/ adalah 0755 agar PHP dapat menyimpan berkas JSON.

3. Sinkronisasi dari Admin CMS

Di website, login ke Akses Pengurus (kata sandi bawaan: admin123), buka tab Hosting & Server, lalu klik "Kirim / Simpan ke Direktori gepekristretes.org".
