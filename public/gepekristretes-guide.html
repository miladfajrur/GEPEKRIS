Panduan Hosting cPanel & Solusi Konten

Mengapa editan di Vercel tidak berubah di HP orang lain, dan panduan lengkap memindahkan ke hosting cPanel.

❓ Mengapa perubahan di web tidak muncul di perangkat / HP orang lain?

Penyebab Utama: Vercel adalah platform hosting statis (Jamstack). Ketika Anda mengubah isi website di browser Anda, perubahan tersebut hanya tersimpan di localStorage (memori lokal browser HP/laptop Anda sendiri).

Orang lain atau jemaat yang membuka website di HP mereka hanya membuka file statis yang di-deploy pertama kali di Vercel, sehingga mereka tidak bisa melihat perubahan yang Anda simpan di browser Anda.

✅ Solusinya: Hosting di cPanel (Full Stack PHP + React)

Aplikasi ini sudah dilengkapi dengan backend API PHP (api/content.php). Di cPanel, script ini memiliki izin untuk menulis dan menyimpan berkas data/church_content.json langsung di server hosting.

Hasilnya: Setiap kali Anda klik "Publikasikan ke Hosting" di Admin CMS, data tersimpan di server hosting dan SEMUA ORANG di seluruh dunia langsung melihat perubahannya!

🚀 Panduan Lengkap Upload ke Hosting cPanel

Ikuti 5 langkah mudah berikut untuk menjalankan website di cPanel Anda:

1 Build Aplikasi (di Komputer Anda)

Buka terminal di folder project website Anda, lalu jalankan:

npm run build

Perintah ini akan membuat folder baru bernama dist/ yang berisi seluruh website yang sudah siap dipublikasikan.

2 Login ke cPanel Hosting Anda

Buka alamat cPanel Anda (contoh: https://domainanda.com:2083 atau https://cpanel.domainanda.com) menggunakan username & password dari penyedia hosting Anda.

3 Buka File Manager & Masuk ke public_html

Di dashboard cPanel, klik menu File Manager, kemudian klik folder public_html/.

(Catatan: Jika domain Anda adalah addon domain atau subdomain, buka folder yang sesuai dengan root domain tersebut).

4 Upload Seluruh Isi Folder dist/

Upload seluruh isi di dalam folder dist/ ke dalam folder public_html/:

public_html/
├── index.html              (Halaman utama React)
├── index.php               (Loader PHP)
├── .htaccess               (Routing Apache & penonaktifan cache JSON)
├── assets/                 (Folder file CSS & JS)
├── api/
│   ├── content.php         (Script penyimpan & pembaca data)
│   └── .htaccess           (Header CORS API)
└── data/
    ├── church_content.json (Database konten JSON seluruh website)
    └── backups/            (Cadangan otomatis setiap kali ada update)

Tips: Anda dapat mengompres folder dist/ menjadi dist.zip, upload file zip tersebut ke cPanel, lalu klik tombol Extract di File Manager.

5 Atur Izin Folder (CHMOD) data/ ke 755

Di File Manager cPanel, klik kanan pada folder public_html/data → pilih Change Permissions → pastikan nilainya 755 (atau 777) agar script PHP dapat menyimpan perubahan konten.

🎉 Cara Mengupdate Konten Website Setelah di cPanel

  1. Buka website Anda di browser: https://domainanda.com.
  2. Scroll ke footer paling bawah, klik "Akses Pengurus" (kata sandi bawaan: admin123).
  3. Ubah informasi gereja, jadwal ibadah, warta jemaat, atau foto galeri sesuai kebutuhan.
  4. Klik tombol hijau "Publikasikan ke Hosting" di pojok kanan atas.
  5. Selesai! Seluruh jemaat yang membuka website di HP, tablet, maupun komputer akan langsung melihat konten terbaru secara real-time.

⚙️ Opsi Alternatif: Tetap Pakai Vercel tapi Data di cPanel

Jika domain utama Anda ingin tetap dihosting di Vercel, Anda cukup memanfaatkan hosting cPanel sebagai server API:

  1. Upload file api/content.php ke folder public_html/api/content.php di hosting cPanel Anda.
  2. Buka Admin CMS di website Vercel Anda, buka tab Hosting & Server.
  3. Di kolom URL Endpoint API, masukkan alamat lengkap cPanel Anda: https://namadomaincpanel.com/api/content.php.
  4. Klik Uji Koneksi (Ping), lalu klik Publikasikan ke Hosting.
